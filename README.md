# Manoj Devisetti — SAP ABAP Portfolio (Email-Only Version)

This version is a static website focused on SAP ABAP freelancing, with recruiter outreach and mentoring as secondary goals.

## Contact behavior

- No contact form, Formspree, API, database, or backend.
- The **Send freelance inquiry** button opens the visitor's default email application with your email address and a prefilled subject/message.
- The **Email about a role** button opens an email draft for recruiter outreach.
- Your contact email is publicly displayed: manoj.devisetti2002@gmail.com.
- The LinkedIn button opens your profile.
- A visitor must have a working email application configured and actually send the message. You receive it in your normal email inbox, not via a website notification service.

## Host for free on GitHub Pages

1. Sign in at https://github.com and create a public repository named `sap-abap-portfolio`.
2. Upload `index.html` to the root of the repository and commit it.
3. Open Settings > Pages > Build and deployment.
4. Select Deploy from a branch, branch `main`, folder `/(root)`, then Save.
5. Your website should appear at `https://YOUR_USERNAME.github.io/sap-abap-portfolio/` after deployment.
6. Test the email button on desktop and mobile, and verify that your email program opens a draft.
